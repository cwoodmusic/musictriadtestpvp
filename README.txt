MUSIC TRIAD PvP PROTOTYPE

This is deliberately separate from the stable single-player Music Triad build.

TEST:
1. Upload index.html to a separate GitHub Pages test repo/site (recommended), OR open the deployed test URL.
2. Open the same URL on two different browsers/devices.
3. Device A: CREATE GAME.
4. Device B: enter the four-character code and JOIN GAME.
5. Play a complete 3x3 game.
